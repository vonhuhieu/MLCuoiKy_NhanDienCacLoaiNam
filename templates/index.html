Kiến Trúc Microservices: Spring Boot + VueJS + MySQL + Python AI Service

Đây là kiến trúc chuẩn của các hệ thống doanh nghiệp thực tế: Tách biệt rõ ràng giữa tầng hiển thị (Frontend), tầng nghiệp vụ & dữ liệu (Backend Spring Boot + MySQL) và tầng tính toán mô hình AI (Python TensorFlow Service).

1. VueJS Frontend

Giao diện người dùng Reactive, SPA, kéo thả tải ảnh, hiển thị biểu đồ xác suất.

Port: 3000 / 8080

2. Spring Boot API

Quản lý nghiệp vụ, xác thực User, lưu lịch sử nhận diện, gọi Python AI qua REST/Feign.

Port: 8080 (REST)

3. MySQL Database

Lưu trữ 44 loài nấm (bách khoa), bảng lịch sử đoán `prediction_history`, tài khoản.

Database: mushroom_db

4. Python AI Service

FastAPI/Flask tải mô hình Keras (ResNet/DenseNet/MobileNet), suy luận ảnh và trả về Top 5.

Port: 5000 / 8000

Các Bước Tích Hợp Chi Tiết:

  1. Cơ sở dữ liệu MySQL: Đã chuẩn bị sẵn file schema.sql chứa bảng danh mục 44 loài và lịch sử nhận diện.
  2. Python AI Service: Đã xây dựng sẵn app.py chạy Flask, có endpoint POST /api/predict để nhận ảnh từ Spring Boot.
  3. Spring Boot Backend: Tạo Controller nhận MultipartFile từ VueJS, dùng RestTemplate hoặc WebClient gửi sang Python AI, nhận kết quả rồi lưu vào MySQL và trả về VueJS.
  4. VueJS Frontend: Giao diện người dùng có thể dùng trực tiếp giao diện Web hiện tại hoặc build thành dự án Vue 3 (Vite + Pinia + Tailwind) độc lập.
